# Models

The 3D mode's models are generated by the Blender scripts in this directory and written to `public/models` as GLB. Nothing here is hand-edited in the Blender UI, so every model can be rebuilt:

```sh
tools/models/bl tools/models/hippo/build.py
```

`bl` runs Blender headless (set `BLENDER` to its path if it is not in `~/.local/opt`). `common.py` has the helpers every script uses: `reset`, `part`, `empty`, `export_glb`, `report`, `preview`. `preview` re-opens the exported GLB and renders it in a dark room under one flashlight, into `tools/models/previews` (not committed).

## The contract with the game

Sizes are metres. In Blender the model stands on z = 0, centred on the origin, facing -Y. The exporter turns that into three.js axes: +Y up, facing +Z.

A model is a tree of rigid mesh parts with no armature. The game animates parts by name (`public/src/three/`), so the names, the pivots and the rest pose are the interface:

- Every part's origin is the joint it turns about. Rotation and scale are applied (identity at rest).
- Parts overlap at the joints by enough that a 40 degree turn opens no gap.
- A positive turn about a part's local X pitches something that points forward down (a jaw opens), and swings something that hangs down toward the back.
- `_L` is the model's own left, which is +X.

Mascot parts:

| Node | Pivot | Notes |
|---|---|---|
| `root` | origin, on the floor | an empty; the only top-level node |
| `body` | pelvis | torso, hips and the rear. Parent of everything below |
| `neck` | base of the neck | optional |
| `head` | where the head meets the neck | child of `neck` if there is one |
| `jaw` | the hinge | child of `head`. Optional if the mouth cannot open |
| `eye_L`, `eye_R` | centre of the eyeball | children of `head`. The game turns them to look at a player |
| `arm_L`, `arm_R` | shoulder | optional children `forearm_L`, `forearm_R` at the elbow |
| `leg_L`, `leg_R` | hip | optional children `shin_L`, `shin_R` at the knee |
| `extra_N` | where it joins | anything else that moves on a joint: extra limbs, a tail. Chains nest: `extra_1`, child `extra_1_2`, child `extra_1_3` |
| `sway_N` | where it hangs from | soft hanging things the game swings: hair, guts, torn cloth |

Materials named `eye_glow` are drawn emissive and unlit by the game, so they show in the dark. Any other material is ordinary PBR.

Each mascot has three files, `<key>_0.glb`, `<key>_1.glb`, `<key>_2.glb`, one per rot stage, and a `<key>.json` beside them that tells the game what it cannot read from the file (see any of them for the fields).

Limits per file: 70k triangles, 3 MB, textures at most 2048 px. Mascots at stages 0 and 1 fit in a box 2.3 m wide, 1.9 m deep and 2.7 m tall; stage 2 may be 3.3 m tall and 2.6 m wide. Doorways in the building are 2.6 m wide and 3 m high.
